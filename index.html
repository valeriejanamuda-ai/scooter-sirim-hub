Import permit to bring complete electric scooters into Malaysia — HS code, MITI pre-check, manual approval, ePermit and quota.

MITI Battery Approved Permit (AP)
Import permit for scooter lithium batteries brought in separately as spare/replacement or under a battery HS code (effective 1 Jan 2026).
View guide → 📄 AP flowchart
MS IEC 62133 / IEC 62133-2 · UN 38.3 · SDS/MSDS
The three lithium-battery documents — battery safety, transport/shipping safety, and dangerous-goods handling — and how to match them to the shipment.
View guide → 📄 SIRIM battery req. 📄 Garis Panduan 2018
KPDN mySAFE MC Mark (MS IEC 62133)
Mandatory safety-mark check for rechargeable lithium batteries sold in or with scooters; highest risk when sold as a separate spare.
View guide → 📄 Garis Panduan 2018
ST Certificate of Approval (CoA) + ST-SIRIM Label
Electrical-safety approval for the scooter charger/adaptor (ST Category 33) — ST CoA, SIRIM consignment test, then ST-SIRIM label before sale.
View guide → 📄 Electrical equipment guidelines
SIRIM eComM Type / Hybrid / Special Approval (MCMC)
Communications approval when the scooter has any wireless module (Bluetooth, WiFi, GPS, 4G/SIM, app control) — choose Type, Hybrid or Special Approval.
View guide → 📄 Type Approval 📄 Special Approval
IP54 / IP65 Ingress Report (IEC 60529 / MS IEC 60529)
Test report needed to back any dust/water (IP) rating claimed on the listing, label or packaging, and how to avoid over-claiming.
