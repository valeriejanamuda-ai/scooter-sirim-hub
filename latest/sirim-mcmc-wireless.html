SIRIM / MCMC Wireless Approval Flow

Purpose: This guide covers SIRIM/MCMC approval for scooters with wireless/communication functions such as Bluetooth, WiFi, GPS tracker, GSM/4G, NFC, RFID, Zigbee, LoRa, NB-IoT or app control.
Core rule: First confirm whether the scooter has any wireless module. If no wireless module exists, this route is usually not applicable, but keep supplier written confirmation. If wireless exists, ask SIRIM whether Type Approval / Compliance Approval, Hybrid Certification Scheme or Special Approval applies.

2. First Pre-Check

  • Ask supplier whether scooter has Bluetooth, WiFi, GPS, GSM/4G, NFC, RFID, Zigbee, LoRa, NB-IoT, remote/app control or any wireless module.
  • If supplier says no wireless, request written confirmation.
  • If wireless exists, collect wireless module documents before applying.
  • Do not assume CE/FCC or a certified module alone is enough for the whole scooter.

5. Documents from Supplier

- Confirmation whether wireless module exists - Wireless module brand and model - Wireless module datasheet - Frequency band - RF output power - Antenna specification and antenna gain - RF test report - CE/FCC report, if available - Product photos - Internal photos showing module location, if available - User manual - Product label artwork - App/Bluetooth/WiFi/GPS/4G function description - Manufacturer/importer details - Brand authorization letter, if applicable

6. Label / Sticker

If SIRIM/MCMC approval applies, MCMC label / SLP or other marking may be required according to approval conditions. This is separate from MITI AP and ST-SIRIM charger label.

Prepared as an internal guide. Final route and labelling should be confirmed with SIRIM QAS/MCMC for the exact model and wireless module.
