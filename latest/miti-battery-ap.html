MITI Battery AP Flow

Purpose: This guide covers MITI Battery AP checking for new reusable batteries / accumulators related to electric scooters or motor vehicles.
Core rule: Check MITI Battery AP mainly when the battery is imported separately, sold as spare/replacement, or declared under a battery HS code. If battery is inside a complete scooter, the main route may be MITI Micromobility AP, but battery documents are still needed for shipping and technical support.

2. First Pre-Check

  • Confirm whether battery is imported inside complete scooter or separately.
  • Confirm battery HS code with forwarder/customs agent; do not reuse scooter HS code automatically.
  • Ask MITI whether the battery import falls under Battery AP.
  • Prepare UN38.3 + SDS/MSDS regardless for lithium battery shipping/logistics.

4. Document Package

- HS code / Customs classification for battery - Application letter on company letterhead - Company profile / SSM - Importer details - Supplier/manufacturer details - Product catalogue - Battery specification sheet - Battery model number - Battery voltage/capacity/Wh rating - Invoice and packing list - Country of origin - UN38.3 test summary - UN38.3 full test report, if available - SDS/MSDS - IEC 62133 / MS IEC 62133 report, if required/available - Technical Evaluation Report, if required by MITI - DagangNet/ePermit account

5. Quick Flow

1. Confirm whether battery is imported separately or inside complete scooter. 2. Confirm HS code with forwarder/customs agent. 3. Ask MITI whether Battery AP applies. 4. Request supplier battery documents: UN38.3, SDS/MSDS, IEC report if available, battery spec, label and photos. 5. Prepare Technical Evaluation Report only if required. 6. Submit AP through ePermit if MITI confirms Battery AP is required. 7. Use approved AP for customs clearance.
Important: Replacement battery from overseas should be treated as a new import unless MITI/Customs gives written confirmation otherwise.

Prepared as an internal guide. Final applicability depends on HS code, import method and MITI/Customs confirmation.
