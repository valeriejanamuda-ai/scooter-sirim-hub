Charger / Adaptor ST CoA + ST-SIRIM Flow

Purpose: This guide covers scooter charger/adaptor approval in Malaysia, especially Category 33: Adapter / Charger, A.C. - D.C. Chargers.
Core rule: Charger/adaptor approval is separate from MITI scooter AP. The usual route is confirm charger scope → prepare technical documents → apply ST CoA through ePermit → import → SIRIM consignment test via e-CEE → affix ST-SIRIM label before sale.

2. First Pre-Check Before Applying

  • Confirm exact charger model number, input/output, wattage and plug type.
  • Confirm whether the charger is included inside scooter box or imported separately.
  • Check whether supplier already has Malaysia ST CoA for the exact charger model.
  • Ask supplier for Type Test Report / IEC safety report, CB report if available, component list, manual, catalogue, rating label and photos.
  • Do not assume CE/FCC alone is enough for Malaysia sale.

5. Supplier Request Checklist

- Charger model number - Input voltage/frequency - Output voltage/current - Wattage rating - Plug type - Rating label artwork - Charger photos: front/back/plug/cable/label/packaging - Type Test Report / IEC safety report - CB certificate and CB report, if available - EMC report, if available - List of components / BOM - Instruction manual - Product catalogue/datasheet - Manufacturer name and address

6. Key Warning

ST-SIRIM label is not the same as MITI AP. MITI AP covers scooter import permission; charger approval covers electrical safety for the charger/adaptor. A scooter package can need both.
