MITI AP Micromobility Approval Flow

Purpose: This guide explains the MITI Approved Permit (AP) flow for importing micromobility vehicles such as electric scooters into Malaysia, including HS code, MITI pre-check, manual approval, ePermit, quota, repeat batches, defects and replacement scenarios.
Core rule: Do not start paid third-party testing/certification first. Collect supplier basic documents, check HS code, then confirm with MITI whether the scooter is accepted under N150 Micromobility and whether MS2514 is required. Only after MITI confirms the route, proceed with paid testing or third-party documents.

2. MITI AP Category and Important Meaning

Permit TypeMITI Import
AP TypeINQ - Other Vehicle
AP CategoryN150 - Micromobility
AP SubcategoryTo be determined by MITI Approval Letter.
Manual ApprovalUsed to approve/register company + brand/model + specification + quota before ePermit.
ePermit / Online APUsed for actual import shipment after MITI manual approval, usually using invoice, packing list and BL/AWB.
AP ValidityAP is generally valid for 6 months. This normally applies to import/customs clearance, not the sell-through period for goods already legally imported.
MITI Sticker / LabelMITI AP itself usually does not require a MITI sticker/label. However, other approvals may require labels, for example charger ST-SIRIM label, MCMC/SIRIM label for wireless functions, or KPDN MC Mark if applicable.
Classification warning: Confirm with MITI/Customs whether the product is accepted under N150 Micromobility. MITI notes that micromobility AP does not include moped/electric moped. If the scooter is classified as moped/electric moped, the route may be different or may not be accepted under this AP category.

3. Recommended First-Step Flow Before Spending on Third-Party Documents

1. Get Supplier Basic Docs
Catalogue, specs, photos, brand/model, motor, battery, charger, CBU/CKD, country of origin, proforma invoice.
2. Check HS Code
Use HS Explorer for reference, then confirm with forwarder/customs agent.
3. Pre-check with MITI
Ask if product is accepted under N150 Micromobility and whether MS2514 is required.
4. Confirm MS2514 Route
If MITI asks MS2514, enquire with SIRIM/testing body. Do not send samples to wrong lab.
5. Prepare Paid Reports
Only after MITI confirms route, arrange MS2514/other technical reports if required.
6. Manual Approval → ePermit
Submit manual approval, get MITI Approval Letter, then apply online AP in ePermit.

4. Stage 1: Supplier Basic Documents + HS Code Check

1Collect Supplier Documents First

Purpose: MITI, forwarder and testing bodies need basic product documents before they can confirm route, HS code or test requirements.

  • Product catalogue / brochure
  • Full scooter specification sheet
  • Product photos
  • Brand and model / model number
  • Motor specification and wattage
  • Battery specification: voltage, capacity, Wh rating
  • Charger specification
  • Import method: CBU or CKD
  • Country of origin
  • Proforma invoice / invoice, if available
  • Whether battery, charger or spare parts are imported together or separately

2Confirm HS Code / Customs Classification

Purpose: To confirm whether the product falls under micromobility / electric bicycle / electric scooter / other vehicle classification.

How to handle: Use JKDM HS Explorer as a checking tool, then ask the appointed forwarder/customs agent to propose/confirm the HS code. If the product is unclear or MITI requires official confirmation, request Customs classification/ruling.

Status: Mandatory before AP planning

5. Stage 2: MITI Pre-Check Before Paid Testing

3Ask MITI to Confirm the Correct Route

Purpose: Avoid paying for the wrong test/report. This is especially important if the scooter is 500W and has no pedals, because MS2514 is usually linked to electric bicycles / pedal-assisted bicycles.

Send MITI:

  • Supplier catalogue, specs and photos
  • Brand/model
  • Motor/battery/charger details
  • CBU or CKD confirmation
  • Country of origin and quantity
  • Proposed HS code / customs classification, if available

Ask MITI:

  • Is this product accepted under INQ - Other Vehicle / N150 Micromobility?
  • Is MS2514 compliance report required for this exact model?
  • If SIRIM says MS2514 is not applicable, can MITI accept a waiver/written confirmation or alternative document?
  • What documents must be submitted for manual approval?
  • Does this model need manual approval before ePermit?

Status: Recommended before arranging paid third-party testing

6. Stage 3: MS2514 / Alternative Compliance Report

4Only Arrange MS2514 If MITI Confirms It Is Needed

Purpose: To obtain the compliance report required by MITI for micromobility AP, if applicable.

How to enquire with SIRIM/testing body: Email SIRIM QAS customer service with product details and ask which department/lab handles MS2514 testing, sample submission address, quotation, sample quantity, test scope and timeline.

Do not send sample directly to: Photovoltaic (PV) Module Testing Laboratory unless SIRIM specifically instructs. PV Module Testing Laboratory is for solar/photovoltaic modules, not electric scooter/micromobility testing.

Documents usually needed by testing lab:

  • Product catalogue / brochure
  • Full specification sheet
  • Model name and model number
  • Product photos
  • User manual
  • Motor, battery, charger and controller specification
  • Wiring diagram, if available
  • Brake system details
  • Lighting / reflector details, if available
  • Speed limit, max load and tyre size
  • Manufacturer name and address
  • Physical product sample for testing, if required

Status: Mandatory only if MITI requires it

If SIRIM says MS2514 is not needed / not applicable: Get SIRIM’s written confirmation and reason. Then send it to MITI and ask whether MITI accepts the AP application without MS2514 or what alternative document is required. SIRIM can advise testing applicability, but MITI decides whether MS2514 can be waived or replaced for AP.

7. Stage 4: Manual MITI AP Approval

5Prepare and Submit Manual Application

Purpose: Manual approval is normally used to approve/register the company + model + specification + quota before online ePermit AP can be submitted.

How to submit: Start by contacting MITI AP section at ap@miti.gov.my. Submission may be by email, appointment or method instructed by MITI. Confirm directly with MITI before submitting.

Documents required:

  • Application letter using company letterhead
  • Brand and model of micromobility vehicle
  • Form of importation: CKD or CBU
  • Quantity / quota requested
  • Country of origin
  • Company profile / SSM company registration
  • Customs tariff code classification / Appendix 14
  • MS2514 compliance report, or MITI-accepted waiver/alternative document if MS2514 is not applicable
  • Specifications and photos of each micromobility vehicle model
  • Supplier brochure / catalogue
  • Sales report for existing approved models, if applicable

Status: Mandatory for first-time model/quota approval, except sales report is only if applicable.

8. Stage 5: DagangNet / ePermit Online AP Application

6Register / Log In and Submit Online AP

Purpose: To apply for the actual import permit after MITI manual approval/model-quota registration.

Apply through: DagangNet / ePermit Online AP Application

System issue: Contact DagangNet Careline: 1-300-133-133, careline@dagangnet.com, WhatsApp 010-447 5838.

Approval/quota/model issue: Contact MITI AP Team: ap@miti.gov.my, 03-6208 4970 / 03-6208 4945.

Supporting documents usually needed:

  • MITI Approval Letter
  • Application letter using company letterhead
  • Bill of Lading / Airway Bill
  • Invoice and Packing List
  • Technical specification / vehicle photos
  • Additional supporting documents, if requested

Status: Mandatory after MITI Approval Letter is obtained

9. Stage 6: Final Import / Customs Clearance

7Approved AP, Payment and Customs Declaration

Purpose: To use the approved AP for import declaration and customs clearance.

  • Approved online AP / permit
  • Invoice
  • Packing list
  • Bill of Lading / Airway Bill
  • Customs declaration documents / K1
  • Payment through DagangNet / ePermit, if applicable

Status: Mandatory before goods clearance

10. Manual Approval vs ePermit

ItemPurposeWhen UsedKey Documents
Manual MITI Approval Approve/register model, specification and quota. First-time model, new brand/model/spec, new quota, or MITI requests review. Company docs, application letter, HS classification, MS2514/waiver/alternative report, specs/photos/catalogue.
DagangNet / ePermit Online AP Apply AP for actual import shipment. After manual approval, for each shipment/permit depending on invoice/BL/AP quantity. MITI Approval Letter, invoice, packing list, BL/AWB, application letter, technical docs.

12. Quota Meaning and Defect / Replacement Scenarios

Quota meaning: Quota means the approved import quantity. It is normally based on the quantity of units entering Malaysia, not the net quantity sold after returns.
ScenarioCounts as New Import?Uses New Quota / AP?Notes
Customer returns defective unit to your Malaysia warehouseNoNoLocal return only. Keep defect and return records.
You replace customer using existing Malaysia warehouse stockNoNoNo new import. Existing imported stock is used.
You repair locally and return same unit to customerNoNoLocal service/repair movement only.
You export defective unit back to overseas supplierExport, not importNo import quota restored automaticallyExporting defective unit does not automatically refresh original import quota.
Supplier sends replacement unit from overseas to MalaysiaYesLikely yesTreat as new import even if free-of-charge warranty replacement, unless MITI/Customs confirms another treatment in writing.
Supplier sends spare battery from overseasYesCheck MITI Battery APMay need battery AP check, UN38.3, SDS/MSDS, IEC battery report.
Supplier sends charger replacement from overseasYesCheck ST CoA/ST-SIRIM routeCharger may require ST CoA / SIRIM consignment / label depending on import route and approval status.
Safe rule: Replacement units sent from overseas should be treated as new incoming imports and may require new AP/ePermit/quota. Do not assume exported defective units can automatically reuse or restore old quota unless MITI/Customs gives written confirmation.

13. New Quota Decision Flow

Need more import quantity? ↓ Check if same approved model already exists in MITI/ePermit system. ↓ Check if quota balance is still available and valid. ↓ If quota is available: Proceed with ePermit / online AP for new shipment, subject to MITI/ePermit rules. If quota is finished, insufficient, expired, or not registered: Request MITI manual approval / quota update first. After MITI updates/registers quota, apply ePermit / online AP. If brand/model/spec changes: Treat as new model/variant. Manual MITI approval first, then ePermit.

16. MITI Application Letter Content

  • Company name and letterhead
  • Request to apply for MITI AP
  • Permit Type: MITI Import
  • AP Type: INQ - Other Vehicle
  • AP Category: N150 - Micromobility
  • Brand and model
  • Type of vehicle
  • Form of importation: CKD or CBU
  • Quantity / quota requested
  • Country of origin
  • HS code / customs classification, if available
  • Purpose of import
  • List of attached documents
  • Authorised signature and company stamp
Suggested internal drafting only — not official MITI wording:
The imported micromobility vehicles are intended for private area / off-road use only and will not be registered or used on public roads unless permitted by the relevant authorities.

Use this only as internal draft wording if appropriate. Do not present it as MITI’s official required sentence unless MITI confirms it in writing.

18. Quick Copy Summary

MITI AP Micromobility Flow: 1. Collect supplier basic documents first: catalogue, specs, photos, brand/model, motor, battery, charger, CBU/CKD, country of origin and proforma invoice. 2. Check proposed HS code. HS code finder is only a checking tool; final HS code should be confirmed by forwarder/customs agent or Customs if needed. 3. Pre-check with MITI before paid testing: confirm whether product is accepted under INQ - Other Vehicle / N150 Micromobility and whether MS2514 is required. 4. If MITI requires MS2514, enquire with SIRIM/testing body. Do not send sample to PV Module Testing Laboratory unless instructed. 5. If SIRIM says MS2514 is not applicable, get written confirmation and ask MITI whether they accept waiver or alternative document. 6. Prepare manual MITI AP documents and submit manual application to approve/register model and quota. 7. Receive MITI Approval Letter. 8. Register/log in to DagangNet/ePermit and submit online AP using MITI Approval Letter, invoice, packing list, BL/AWB and product documents. 9. Once approved, proceed with payment, permit printing/declaration and customs clearance. 10. MITI AP itself usually does not require a sticker, but charger/wireless/battery approvals may require labels. Scenario rules: - Same exact model/spec with quota balance: usually ePermit only for new shipment. - New brand/model/voltage/wattage/major spec: likely manual approval first. - Quota finished or insufficient: likely MITI manual quota update first, then ePermit. - AP expired but goods already legally imported/cleared: normally no need to renew AP just to continue selling existing warehouse stock. - Overseas warranty replacement units: treat as new import and likely use new quota/AP unless MITI/Customs confirms otherwise.

Prepared as an internal working guide for MITI AP micromobility planning. Final requirements should be confirmed with MITI, DagangNet, Customs, SIRIM/testing body and your forwarding/customs agent before import.
