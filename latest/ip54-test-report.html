IP54 Test Report & Label Guide

Purpose: This guide explains when IP54/IP65 test reports are needed for scooter claims, labels, listings, manuals or packaging.
Core rule: IP54 is not normally an import permit. It is a product claim. If you claim IP54/IP65, you should have a test report according to IEC 60529 / MS IEC 60529 for the exact model/enclosure claimed.

2. What IP54 Means

CodeMeaningSimple Explanation
IPIngress ProtectionProtection against dust/solid particles and water.
5Dust protectedLimited dust may enter, but not enough to interfere with operation.
4Splash protectedProtected against water splashing from any direction.
Do not overclaim: IP54 is not waterproof. Do not claim submersible, flood-proof, pressure-wash safe or fully waterproof unless a higher report supports it.

4. Report Verification Checklist

- IP54/IP65 test report - Test standard: IEC 60529 / MS IEC 60529 - Tested model number - Tested product photos - Test lab name - Lab accreditation details, if available - Test date - Result clearly showing IP54/IP65 - Confirmation tested model matches selling model - Scope of test: whole scooter or only component/enclosure

5. Label / Manual Wording

Not an authority sticker: IP54/IP65 is a claim label/manual/listing wording, not a MITI/SIRIM approval sticker. Use wording only if supported by report.
Suggested wording: IP54 dust and splash resistant. Not waterproof. Do not submerge in water. Do not ride through floodwater or wash with high-pressure water. Ensure charging port is closed before use.

6. Quick Summary

1. Only claim IP54/IP65 if a matching IEC 60529 / MS IEC 60529 report exists. 2. Check if report covers whole scooter or only a component. 3. If enclosure, charging port, cover or battery compartment changes, re-check report validity. 4. IP54 is splash-resistant, not waterproof. 5. Keep report for listing, packaging, warranty and customer dispute support.

Prepared as an internal guide. Final claim wording should match the actual test report and product design.
