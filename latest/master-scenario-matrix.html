Scooter Compliance Master Scenario Matrix

Purpose: This master matrix helps decide which approval/checklist page to use when scooter model, shipment, battery, charger, wireless function or product claims change.
Core rule: Start with supplier basic documents and HS code/MITI pre-check. Then check the relevant approval based on what changed: scooter model, charger, battery, wireless module, IP claim or shipment scenario.

2. Decision Rules

1. Scooter model/brand/spec changed → check MITI AP manual approval. 2. Charger model/rating changed → check ST CoA and ST-SIRIM label. 3. Wireless added/changed → check SIRIM/MCMC approval. 4. Battery imported separately or changed → check MITI Battery AP, KPDN MC Mark and battery reports. 5. IP54/IP65 claimed → require matching IEC 60529 / MS IEC 60529 report. 6. Replacement from overseas → treat as new import unless authority confirms otherwise. 7. Existing legally imported stock → AP expiry usually does not stop selling, but other labels/approvals must already be compliant. 8. Suggested wording in internal guides is not official authority wording unless confirmed in writing.
This master matrix is a shortcut only. Always confirm with MITI, ST, SIRIM, KPDN, Customs, forwarder or the relevant authority for the exact product
