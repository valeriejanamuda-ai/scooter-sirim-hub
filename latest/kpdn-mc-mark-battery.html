KPDN MC Mark for Secondary Battery

Purpose: This guide covers KPDN mySAFE / MC Mark checking for secondary rechargeable lithium batteries used in or sold with electric scooters.
Core rule: Confirm applicability first. Battery sold separately as spare/replacement has higher risk of MC Mark requirement. Battery inside a complete scooter still needs checking, but do not assume MC Mark is required or not required without KPDN/SIRIM confirmation.

2. First Pre-Check

  • Confirm whether battery is sold separately or only inside scooter.
  • Confirm whether the battery is removable and labelled as a separate product.
  • Ask KPDN/SIRIM whether MC Mark applies to this exact battery model and sales method.
  • Do not assume “not fully enforced” means not needed permanently.
  • Get written confirmation if authority says not applicable.

3. Applicability Scenarios

Same battery model repeat shipmentUsually same report if exact model unchangedModel, manufacturer, voltage/capacity and cell must match.

Overseas replacement batteryNew import checkAlso check MITI Battery AP, UN38.3, SDS/MSDS.

4. Documents Needed

- Battery model number - Battery specification sheet - Voltage, capacity and Wh rating - Cell brand/model and cell datasheet - Cell chemistry: lithium-ion / LiFePO4 etc. - Battery manufacturer name and address - BMS specification - Protection details: overcharge, over-discharge, short circuit, overcurrent, temperature - Battery label artwork - Battery photos: front/back/connector/label - MS IEC 62133:2017 / IEC 62133-2 test report or CB report, if available - Factory ISO 9001, if available - Product sample, if requested

5. Label / Sticker

MC Mark / conformity marking should only be used if the product is approved/allowed under the applicable KPDN/SIRIM route. Do not place MC Mark unless confirmed and permitted.

6. Quick Summary

1. Confirm whether battery is sold separately or only inside scooter. 2. Ask KPDN/SIRIM whether MC Mark applies. 3. Prepare MS IEC 62133 / IEC 62133-2 report if required. 4. If supplier changes cell/BMS/voltage/capacity/manufacturer, re-check report validity. 5. Overseas replacement/spare battery is a new import and should also be checked under MITI Battery AP and shipping documents.

Prepared as an internal guide. Final applicability should be confirmed with KPDN mySAFE / SIRIM QAS for the exact battery model and selling method.
