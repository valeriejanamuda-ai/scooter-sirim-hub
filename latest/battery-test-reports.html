Battery Reports: MS IEC 62133 / IEC 62133-2, UN38.3, SDS/MSDS

Purpose: This guide explains the main scooter lithium battery documents: product safety report, transport safety report and safety handling document.
Core rule: These documents are not interchangeable. MS IEC 62133 / IEC 62133-2 = battery safety. UN38.3 = lithium battery transport safety. SDS/MSDS = safety handling and dangerous goods information.

4. Verification Checklist

- Battery model number matches invoice, label and report - Voltage, capacity and Wh rating are consistent - Manufacturer name is consistent - Cell model and battery pack model are clear - UN38.3 covers the actual shipped battery/cell/pack - SDS/MSDS is readable and recent enough for carrier/forwarder - Reports show test standard, test lab, test date and pass result - If battery pack changed, do not reuse old report blindly

5. Supplier Request

Please provide: - MS IEC 62133:2017 / IEC 62133-2 test report or CB report, if available - UN38.3 test summary - UN38.3 full test report, if available - SDS/MSDS - Battery specification sheet - Battery model number - Voltage, capacity and Wh rating - Battery dimensions and gross/net weight - Cell brand/model and cell datasheet - Battery manufacturer name and address

6. Quick Summary

1. IEC 62133 = battery safety. 2. UN38.3 = transport/shipping safety. 3. SDS/MSDS = handling and hazard information. 4. Reports are model-specific. 5. If battery cell, BMS, voltage, capacity, Wh or manufacturer changes, re-check report validity. 6. Replacement battery shipments still need UN38.3 + SDS/MSDS. 7. Do not ship damaged lithium batteries casually; check dangerous goods handling with carrier/forwarder.

Prepared as an internal guide. Final document acceptance depends on the authority, carrier, forwarder, testing lab and exact battery classification.
