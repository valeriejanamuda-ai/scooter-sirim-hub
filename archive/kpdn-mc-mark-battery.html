KPDN MC Mark for Secondary Battery

Purpose: This guide explains the compliance flow for secondary rechargeable lithium batteries under KPDN mySAFE / Conformity Mark (MC) checking.
Simple summary: This route is for secondary batteries, meaning rechargeable batteries. For scooter battery, this is mainly about battery safety certification / MC Mark checking, using MS IEC 62133:2017 / IEC 62133 as the key safety standard.

4. Flow Details

1Confirm Battery Scope

Purpose: Confirm whether the scooter battery needs KPDN MC Mark / secondary battery safety certification.

Ask / confirm:

  • Is the battery sold separately as a replacement battery?
  • Is the battery only included inside the scooter?
  • Is the battery removable?
  • Is it lithium-ion or LiFePO4?
  • Does the battery label identify it as a standalone product?
  • Does KPDN / SIRIM QAS require MC Mark for this battery category?

Status: Mandatory first step

2Collect Battery Technical Documents

Documents needed from supplier / manufacturer:

  • Battery model number
  • Battery specification sheet
  • Battery voltage, for example 36V
  • Battery capacity, for example 6Ah / 7.8Ah
  • Battery energy rating, for example 216Wh / 280.8Wh
  • Lithium cell datasheet
  • Cell brand and model
  • Cell chemistry, for example lithium-ion or LiFePO4
  • BMS specification
  • Battery pack wiring diagram
  • Battery protection details: overcharge, over-discharge, short circuit, overcurrent, temperature protection
  • Battery label artwork
  • Battery photos: front, back, connector, label
  • Internal battery photos, if available
  • Manufacturer name and address
  • Factory ISO 9001 certificate, if available

Status: Mandatory for application preparation

3Prepare MS IEC 62133 / IEC 62133 Test Report

Purpose: Show battery safety compliance for rechargeable lithium battery.

Acceptable evidence may include:

  • Existing MS IEC 62133:2017 report
  • Existing IEC 62133-2 report
  • CB report/certificate for IEC 62133-2, if available
  • New test report from SIRIM or accredited/accepted lab, if supplier report is not accepted

Status: Likely mandatory if MC Mark / secondary battery certification applies

4Apply Certification / MC Mark Route

Purpose: Submit the battery safety certification / MC Mark application if required.

Documents normally prepared:

  • Company / importer details
  • SSM company registration
  • Battery technical documents
  • MS IEC 62133 / IEC 62133 test report
  • Product catalogue / battery datasheet
  • Battery label artwork
  • Manufacturer details
  • Factory quality documents, if requested
  • Samples for testing, if required

Status: Required if KPDN / SIRIM QAS confirms MC Mark applies

6. Message to Supplier

Hi, for Malaysia KPDN MC Mark / secondary battery safety checking, please provide the battery safety documents for the scooter battery. Required documents: - Battery model number - Battery specification sheet - Battery voltage and capacity - Battery Wh rating - Cell brand/model and cell datasheet - Cell chemistry - BMS specification - Battery protection details - Battery wiring diagram - Battery label artwork - Battery photos - MS IEC 62133:2017 / IEC 62133-2 test report or CB report, if available - Manufacturer name and address - Factory ISO 9001 certificate, if available

7. Message to KPDN / SIRIM QAS

Dear Sir/Madam, We would like to seek confirmation whether KPDN MC Mark / secondary battery safety certification is required for our electric scooter battery. Product: Electric scooter battery / rechargeable lithium battery pack Battery voltage: 36V Battery capacity: 6Ah / 7.8Ah Battery energy: 216Wh / 280.8Wh Battery sold as: [inside complete scooter / replacement battery sold separately] Battery chemistry: [Lithium-ion / LiFePO4] Kindly advise whether MC Mark is required, and whether MS IEC 62133:2017 / IEC 62133-2 test report is acceptable. Please also advise the application process, required documents, sample requirements and estimated processing time. Thank you.

8. Quick Copy Summary

KPDN MC Mark for Secondary Battery Flow: 1. Confirm whether scooter battery falls under KPDN secondary battery MC Mark requirement. 2. Check whether battery is sold separately or only included inside complete scooter. 3. Request supplier documents: battery spec, cell datasheet, BMS details, battery label, battery photos, protection details. 4. Prepare MS IEC 62133:2017 / IEC 62133-2 test report or CB report if available. 5. Submit enquiry to KPDN / SIRIM QAS to confirm applicability. 6. If required, apply for certification / MC Mark and provide sample if requested. 7. Keep approval, test report and label records before sale.

Prepared as an internal working guide. Final applicability and enforcement should be confirmed with KPDN mySAFE / SIRIM QAS for the exact battery model and sales method.
