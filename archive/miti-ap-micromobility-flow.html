MITI AP Micromobility Approval Flow

Purpose: This guide explains the MITI Approved Permit (AP) flow for importing micromobility vehicles such as electric scooter / electric bicycle type products into Malaysia.
Simple summary: The MITI AP flow has 2 stages: Manual MITI Approval first, then DagangNet / ePermit Online AP Application for the actual shipment.

Application MethodManual AP application first, then online AP application via DagangNet / ePermit
Estimated Processing TimeMinimum 2 weeks / around 10 working days, subject to MITI review
Important: Confirm the HS code and product classification first. MITI notes that micromobility AP does not include moped / electric moped. If the product is considered moped / electric moped instead of micromobility, the route may be different or may not be accepted under this AP category.

4. Stage 1: HS Code Verification

1Confirm HS Code / Customs Classification

Purpose: To confirm whether the product falls under micromobility / electric bicycle / electric scooter / other vehicle classification.

Who handles: Forwarding agent, customs agent, or Customs classification route.

Documents to prepare:

  • Product catalogue / brochure
  • Full scooter specification sheet
  • Product photos
  • Model name and model number
  • Battery specification
  • Motor wattage
  • Charger details
  • Invoice / proforma invoice, if available

Status: Mandatory

5. Stage 2: Manual MITI AP Application

2Prepare MITI Manual Application Documents

Purpose: To get MITI manual approval for the micromobility model/category.

Documents required:

  • Application letter using company letterhead
  • Company profile / SSM company registration
  • Customs tariff code classification / Appendix 14
  • MS2514 compliance report / test report
  • Specifications and photos of each micromobility vehicle model
  • Supplier brochure / catalogue
  • Sales report for existing approved models, if applicable

Status: Mandatory, except sales report is only if applicable.

7. MS2514 Compliance Report

3Arrange MS2514 Testing / Assessment

Purpose: To obtain the compliance report required by MITI for micromobility AP.

Documents usually needed by testing lab:

  • Product catalogue / brochure
  • Full specification sheet
  • Model name and model number
  • Product photos
  • User manual
  • Motor specification
  • Battery specification
  • Charger specification
  • Controller specification, if available
  • Wiring diagram, if available
  • Brake system details
  • Lighting / reflector details, if available
  • Speed limit details
  • Max load
  • Tyre size
  • Manufacturer name and address
  • Physical product sample for testing, if required

Status: Mandatory if MITI requires MS2514 report

Important: MS2514 is commonly linked to electric bicycles / electric pedal-assisted bicycles. If the product is a 500W electric scooter with no pedals, confirm with MITI or the testing body whether MS2514 is the correct standard before paying for testing.

8. Stage 3: Submit Manual AP Application to MITI

4MITI Manual Approval

Purpose: To receive the MITI Approval Letter for the micromobility AP route.

Possible outcome:

  • Approved: MITI issues Approval Letter
  • Rejected: Review MITI remarks and correct/reapply
  • Queried: Submit additional documents or clarification

Status: Mandatory before online DagangNet / ePermit AP stage

9. Stage 4: DagangNet / ePermit Online AP Application

5Register / Log In to DagangNet

Purpose: To access the online AP application system.

  • Existing company: log in using existing DagangNet / ePermit account.
  • New company: register first and wait for registration approval.

Status: Mandatory

6Submit Online AP Application

Purpose: To apply for the actual AP for import/shipment after MITI manual approval.

Supporting documents usually needed:

  • MITI Approval Letter
  • Application letter using company letterhead
  • Bill of Lading / Airway Bill
  • Invoice and Packing List
  • Technical specification / vehicle photos
  • Additional supporting documents, if requested

Status: Mandatory after MITI Approval Letter is obtained

10. Final Import / Customs Clearance

7Approved AP, Payment and Customs Declaration

Purpose: To use the approved AP for import declaration and customs clearance.

Documents involved:

  • Approved online AP / permit
  • Invoice
  • Packing list
  • Bill of Lading / Airway Bill
  • Customs declaration documents
  • Payment through DagangNet / ePermit, if applicable

Status: Mandatory before goods clearance

11. Application Letter Content

The MITI application letter should include:

  • Company name and letterhead
  • Request to apply for MITI AP
  • Permit Type: MITI Import
  • AP Type: INQ - Other Vehicle
  • AP Category: N150 - Micromobility
  • Brand and model
  • Type of vehicle
  • Form of importation: CKD or CBU
  • Quantity
  • Country of origin
  • HS code / customs classification, if available
  • Purpose of import
  • List of attached documents
  • Authorised signature and company stamp
Suggested wording:
The imported micromobility vehicles are intended for private area / off-road use only and will not be registered or used on public roads unless permitted by the relevant authorities.

13. Quick Copy Summary

MITI AP Micromobility Flow: 1. Confirm HS code / customs classification. 2. Confirm product category is accepted under INQ - Other Vehicle / N150 Micromobility. 3. Request supplier documents: specs, photos, brochure/catalogue, model details, country of origin. 4. Arrange MS2514 compliance report if required by MITI. 5. Prepare company documents: application letter, company profile, SSM. 6. Submit manual MITI AP application. 7. Receive MITI Approval Letter. 8. Register/log in to DagangNet / ePermit. 9. Submit online AP application with MITI Approval Letter, invoice, packing list, BL/AWB and product documents. 10. Once approved, proceed with payment, permit printing/declaration and customs clearance.
