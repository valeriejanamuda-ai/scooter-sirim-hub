IP54 Test Report & Label Guide

Purpose: This guide explains how to support an IP54 dust/water resistance claim for an electric scooter or battery/charger enclosure, and what documents are needed if IP54 is claimed on listing, packaging, label or brochure.
Simple summary: IP54 is not usually a separate import approval by itself. It is a product claim. If you advertise or label the scooter as IP54, you should keep an IP54 test report according to IEC 60529 / MS IEC 60529 to prove the claim.

2. What IP54 Means

CodeMeaningSimple Explanation
IPIngress ProtectionProtection against entry of dust/solid particles and water.
5Dust protectedLimited dust may enter, but not enough to interfere with operation.
4Splash protectedProtected against water splashing from any direction.
Important: IP54 does not mean waterproof. Do not claim waterproof, submersible, washable by pressure washer, or suitable for flooding unless the report supports a higher rating and the exact use condition.

5. Flow Details

1Confirm IP Claim

Check all materials:

  • Supplier catalogue
  • Product listing
  • Packaging
  • Product label
  • User manual
  • Marketing images

Status: Mandatory

2Request IP54 Test Report

Documents needed from supplier:

  • IP54 test report
  • Test standard used: IEC 60529 / MS IEC 60529
  • Tested model number
  • Tested product photos
  • Test lab name
  • Lab accreditation details, if available
  • Test date
  • Result clearly showing IP54
  • Confirmation tested model matches selling model

Status: Mandatory if IP54 is claimed

3Verify the Report

Check these points before using the report:

  • Model number in report matches the scooter model you will sell.
  • Photos in the report match the same design / enclosure / battery cover.
  • Report states IEC 60529 or MS IEC 60529.
  • Result clearly states IP54, not only IPX4 or dust test only.
  • Report is from a recognizable testing lab.
  • Report is not for only one component if you claim the whole scooter is IP54.

Status: Mandatory

4Arrange New Test If Needed

When needed:

  • Supplier cannot provide IP54 report.
  • Report model number does not match.
  • Report only covers battery box, not whole scooter.
  • Report only says “waterproof” without IEC 60529 details.
  • Buyer/authority asks for local/accredited test report.

Possible testing body: SIRIM or another accredited lab that can test according to IEC 60529 / MS IEC 60529.

Status: If supplier report is missing/not acceptable

5Prepare Accurate Label / Manual Wording

Use wording like:

IP54 dust and splash resistant. Not waterproof. Do not submerge in water. Do not ride through floodwater or wash with high-pressure water. Ensure charging port is closed before use.

Status: Mandatory if IP54 appears on label/marketing

7. Message to Supplier

Hi, for the IP54 claim, please provide the IP54 test report according to IEC 60529 or MS IEC 60529. The report should show: - Tested model number - Test standard used - Test lab name - Test date - Result showing IP54 - Photos of the tested product - Confirmation that the tested model is the same as the model we will import/sell - Lab accreditation details, if available

8. Quick Copy Summary

IP54 Test Report & Label Flow: 1. Check whether IP54 is claimed on catalogue, listing, packaging, label or manual. 2. If IP54 is claimed, request IP54 test report according to IEC 60529 / MS IEC 60529. 3. Verify model number, photos, standard, lab name, test date and result. 4. If report is missing or not matching, arrange new test with SIRIM/accredited lab. 5. Use accurate label/manual wording: IP54 dust and splash resistant, not waterproof. 6. Do not claim waterproof or flood/submersion protection unless separately tested and proven.

Prepared as an internal working guide. IP54 is usually a claim-support document, not a standalone import approval, but inaccurate claims can cause compliance, warranty or customer dispute risk.
