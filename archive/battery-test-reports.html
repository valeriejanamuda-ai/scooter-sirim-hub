Battery Reports: MS IEC 62133:2017 / IEC 62133-2, UN38.3, SDS/MSDS

Purpose: This guide explains the main battery documents needed for scooter lithium batteries: battery safety report, transport safety report, and safety handling document.
Simple summary: These documents are not the same. MS IEC 62133 / IEC 62133-2 is for battery product safety. UN38.3 is for lithium battery transport safety. SDS/MSDS is for chemical/safety handling information.

2. Difference Between the Documents

DocumentPurposeNeeded ForNot a Replacement For
MS IEC 62133:2017 / IEC 62133-2 Battery safety test report for rechargeable lithium cells/batteries. Battery safety certification, KPDN MC Mark check, technical evaluation, product safety file. Does not replace UN38.3 shipping report.
UN38.3 Lithium battery transport safety test report/summary. Shipping, forwarder, airline/sea carrier, customs/logistics documentation. Does not replace MS IEC 62133 product safety report.
SDS / MSDS Safety Data Sheet / Material Safety Data Sheet for chemical/safety handling. Shipment handling, dangerous goods review, warehouse safety, emergency response. Does not replace test reports.

5. MS IEC 62133:2017 / IEC 62133-2

1Battery Product Safety Report

Purpose: Safety test report for rechargeable lithium battery/cell product safety.

Ask supplier for:

  • MS IEC 62133:2017 test report, or
  • IEC 62133-2 test report, or
  • CB certificate/report to IEC 62133-2, if available

Check the report includes:

  • Battery model number
  • Cell model number
  • Battery manufacturer name
  • Voltage and capacity
  • Test standard
  • Test lab name
  • Test date
  • Pass result

Status: Important for battery safety / KPDN MC Mark / technical file

6. UN38.3

2Lithium Battery Transport Report

Purpose: Shows the lithium battery has passed transport safety tests before shipping.

Ask supplier for:

  • UN38.3 test summary
  • UN38.3 full test report, if available
  • Battery model number matching invoice/product label
  • Battery Wh rating
  • Battery gross/net weight and dimensions

Status: Usually mandatory for lithium battery shipment/logistics

7. SDS / MSDS

3Safety Handling Document

Purpose: Provides chemical, safety, hazard, storage, handling and emergency information.

Check SDS/MSDS includes:

  • Product/battery identification
  • Manufacturer/supplier information
  • Composition/information on ingredients
  • Hazards identification
  • First-aid measures
  • Fire-fighting measures
  • Accidental release measures
  • Handling and storage
  • Transport information
  • Disposal information
  • Issue date / revision date

Status: Usually mandatory for shipment/logistics and warehouse safety file

10. Quick Copy Summary

Battery Reports Summary: - MS IEC 62133:2017 / IEC 62133-2 = battery safety report for rechargeable lithium battery. - UN38.3 = lithium battery transport safety report for shipping/import logistics. - SDS/MSDS = safety handling document for chemical/dangerous goods handling. Correct flow: 1. Confirm exact battery model, voltage, capacity and Wh rating. 2. Request MS IEC 62133 / IEC 62133-2, UN38.3 and SDS/MSDS from supplier. 3. Check all documents match the same battery model and manufacturer. 4. Use UN38.3 + SDS/MSDS for shipping/logistics. 5. Use MS IEC 62133 / IEC 62133-2 for battery safety, KPDN MC Mark check and technical file. 6. Arrange new testing if supplier reports are missing, outdated or not accepted.

Prepared as an internal working guide. Final document acceptance depends on the authority, carrier, forwarder, testing lab and exact battery classification.
