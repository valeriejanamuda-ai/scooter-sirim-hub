Charger / Adaptor Approval Flow in Malaysia

Purpose: This guide explains the approval flow for scooter charger/adaptor in Malaysia, especially for Category 33: Adapter / Charger, Subcategory: A.C. - D.C. Chargers.
Simple summary: For charger/adaptor, the usual flow is ST CoA application → import shipment → SIRIM consignment test → ST-SIRIM label → sell/distribute.

3. Flow Details

1Company Registration / Access

Purpose: Make sure the company has the required account/access to submit charger approval.

Platforms:

  • e-DIK / ST: https://edik.st.gov.my/
  • ePermit DagangNet: https://epermit.dagangnet.com.my/

Documents needed:

  • SSM company registration
  • Company profile
  • Authorised PIC details
  • Company letterhead
  • DagangNet / ePermit account
  • COR / ST registration, if required

Who prepares: Importer / your company.

Status: Mandatory

2Prepare Charger Technical Documents

Purpose: Collect all charger documents before applying ST CoA.

Documents needed from supplier:

  • Charger model number
  • Charger technical specification sheet
  • Input voltage / frequency, for example 100-240V~, 50/60Hz
  • Output voltage / current, for example 42V DC, 1.5A or 2A
  • Wattage rating
  • Type Test Report / IEC safety test report
  • CB certificate and CB report, if available
  • List of components / BOM
  • Instruction manual
  • Product catalogue / datasheet
  • Rating label artwork
  • Clear charger photos: front, back, plug, cable, label, packaging
  • Plug type details
  • Manufacturer name and address

Status: Mandatory for core documents. CB report and EMC report are strongly recommended if available.

3Apply ST CoA

Purpose: Apply Certificate of Approval for the charger/adaptor.

Platform: ePermit DagangNet / Suruhanjaya Tenaga.

Guideline: ST Guidelines for the Approval of Electrical Equipment, Category 33: Adapter / Charger, Subcategory A.C. - D.C. Chargers.

Documents normally required:

  • Online CoA application form
  • Type Test Report
  • List of components
  • Instruction manual
  • Technical specification
  • Product catalogue
  • Product sample, if requested
  • Company registration / applicant details
  • Payment / application fee

Important: Make sure the charger model number is consistent across the test report, label artwork, catalogue, invoice, packing list and actual charger.

Status: Mandatory if charger is regulated

4ST Review and Approval

Purpose: ST reviews the charger application and documents.

Possible outcome:

  • Approved: ST issues CoA
  • Queried: Additional documents/corrections required
  • Rejected: Need to correct issue and reapply

Status: ST CoA must be approved before moving to ST-SIRIM label stage

5Import Shipment

Purpose: Import the approved charger/adaptor shipment into Malaysia.

Documents needed:

  • Approved ST CoA
  • Commercial invoice
  • Packing list
  • Bill of Lading / Airway Bill
  • Customs declaration documents
  • Charger model and rating details

Who prepares: Supplier provides invoice and packing list. Forwarder provides shipping/customs documents. Importer keeps CoA records.

Status: Mandatory

6SIRIM Consignment Test

Purpose: SIRIM checks the actual imported charger batch before ST-SIRIM labels are issued.

Platform: e-CEE SIRIM: https://e-cee.sirim.my/

Documents normally needed:

  • ST CoA copy
  • Invoice
  • Packing list
  • Bill of Lading / Airway Bill
  • Customs clearance / K1, if applicable
  • Product photos
  • Quantity to label
  • Warehouse / inspection location
  • Contact person details
  • Sample availability for inspection/testing

Status: Mandatory after ST CoA approval and before ST-SIRIM label issuance

7ST-SIRIM Label

Purpose: Purchase and affix the ST-SIRIM label before selling/distributing the charger or scooter set with charger.

Documents / actions needed:

  • Passed SIRIM consignment test result
  • Payment for labels
  • Label quantity based on approved consignment quantity
  • Affix ST-SIRIM label before sale/distribution

Status: Mandatory before selling regulated charger/adaptor

6. Quick Copy Summary

Charger / Adaptor Approval Flow: 1. Confirm charger is under Category 33: Adapter / Charger, A.C. - D.C. Chargers. 2. Register / prepare company access: e-DIK, DagangNet / ePermit. 3. Request supplier documents: charger specification, Type Test Report, component list, manual, catalogue, rating label and photos. 4. Apply ST CoA through ePermit DagangNet. 5. If ST queries, submit additional documents/corrections. 6. Once ST CoA is approved, proceed with import shipment. 7. After shipment arrives and clears Customs, apply SIRIM consignment test through e-CEE. 8. After consignment test passes, purchase/receive ST-SIRIM labels. 9. Affix ST-SIRIM label before sale/distribution.

7. Key Reminder

CE/FCC alone is usually not enough for Malaysia sale. For regulated charger/adaptor, the usual local requirement is ST CoA + SIRIM consignment test + ST-SIRIM label before sale/distribution.
