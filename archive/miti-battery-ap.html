MITI Battery AP Flow

Purpose: This guide explains the MITI Approved Permit (AP) check for new reusable batteries / accumulators for motor vehicles, including batteries related to electric scooters or vehicles.
Simple summary: MITI Battery AP is mainly relevant when the battery is imported separately, or when Customs/MITI treats the battery under motor vehicle battery import requirements. For complete scooter import, the main route may still be MITI AP - Micromobility, but battery AP should be checked if battery is separately declared or sold as replacement battery.

2. When Is MITI Battery AP Applicable?

SituationMITI Battery AP Check Needed?Remarks
Battery imported separately as spare/replacement batteryYes, must checkBattery may be declared separately under battery import rules.
Battery imported together inside complete scooterCheckMain route may be MITI Micromobility AP, but battery AP check may still be needed depending on HS code and Customs/MITI treatment.
Complete scooter imported as CBUCheck separatelyMay use MITI AP - Micromobility for complete vehicle. Battery documents still needed as supporting/shipping documents.
Charger/adaptor onlyNo, different routeCharger is under ST CoA + ST-SIRIM Label, not MITI Battery AP.
Important: MITI states that all importations of new reusable batteries / accumulators for motor vehicles under headings 87.01, 87.02, 87.03, 87.04, 87.05, 87.09 and 87.11 require AP from MITI effective 1 January 2026. For scooters, 87.11 may be relevant if the goods are classified under electric motorcycle/scooter categories.

4. Flow Details

1Confirm HS Code / Customs Classification

Purpose: Confirm whether the imported item is classified as standalone battery, complete scooter/vehicle, or vehicle part.

Documents to prepare for customs/agent:

  • Battery specification sheet
  • Battery model number
  • Battery photos and label
  • Product catalogue
  • Battery purpose, for example electric scooter replacement battery
  • Invoice / proforma invoice
  • Packing list, if available

Status: Mandatory first step

2Collect Battery Technical and Safety Documents

Documents needed from supplier:

  • Battery model number
  • Battery specification sheet
  • Battery voltage, for example 36V
  • Battery capacity, for example 6Ah / 7.8Ah
  • Battery energy rating, for example 216Wh / 280.8Wh
  • Battery dimensions and weight
  • Cell brand and model
  • Cell chemistry, for example lithium-ion or LiFePO4
  • Battery manufacturer name and address
  • UN38.3 test summary
  • UN38.3 full test report, if available
  • SDS / MSDS
  • IEC 62133-2 / MS IEC 62133 report, if available
  • Technical Evaluation Report, if already available

Status: Mandatory for checking/application preparation

3Prepare MITI AP Application Documents

MITI battery AP document package may include:

  • Customs Classification Letter / HS code classification
  • Application letter using company letterhead
  • Company profile
  • SSM company registration
  • Importer details
  • Supplier / manufacturer details
  • Product catalogue
  • Battery specification sheet
  • Battery model number
  • Invoice
  • Packing list
  • Country of origin
  • UN38.3 test summary
  • IEC report, if required
  • Technical Evaluation Report, if required
  • DagangNet / ePermit account

Status: Mandatory if MITI Battery AP applies

4Technical Evaluation Report

Purpose: Provide technical evidence for battery safety/compliance if MITI requests it.

Possible supporting documents:

  • UN38.3 report / summary
  • IEC 62133-2 / MS IEC 62133 report
  • UN R136 / relevant EV battery system report, if applicable
  • Battery specification and cell datasheet
  • BMS protection information
  • Battery label and model identification

Status: If required by MITI

5Submit AP Application

Platform: DagangNet / ePermit: https://epermit.dagangnet.com.my/

Purpose: Apply for MITI AP before importing the battery.

Possible outcome:

  • Approved: proceed with import/customs clearance
  • Queried: submit additional documents or clarification
  • Rejected: review reason and reapply if appropriate

Status: Mandatory if battery falls under AP requirement

7. Quick Copy Summary

MITI Battery AP Flow: 1. Confirm whether battery is imported separately or together with complete scooter. 2. Confirm HS code / customs classification. 3. Check whether battery falls under MITI Battery AP scope. 4. Request supplier documents: battery spec, UN38.3, SDS/MSDS, IEC report if available, invoice, packing list, country of origin. 5. Prepare company documents and application letter. 6. Prepare Technical Evaluation Report if required. 7. Submit AP application through DagangNet/ePermit if applicable. 8. Use approved AP for customs clearance.

Prepared as an internal working guide. Final MITI Battery AP applicability should be confirmed with MITI, Customs and your forwarding/customs agent based on the exact HS code and import method.
