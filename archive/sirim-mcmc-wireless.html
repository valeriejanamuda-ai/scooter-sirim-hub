SIRIM / MCMC Wireless Approval Flow

Purpose: This guide explains when and how to handle SIRIM / MCMC approval for a scooter that has wireless or communication functions such as Bluetooth, WiFi, GPS tracker, GSM / 4G, NFC, RFID, Zigbee, LoRa, NB-IoT or app control.
Simple summary: SIRIM / MCMC approval is only relevant if the scooter has a wireless / radio / communication module. If the scooter has no Bluetooth, WiFi, GPS communication, GSM / 4G, NFC or similar module, this section is usually not applicable.

3. Which Route: Type Approval, Hybrid Certification or Special Approval?

Route Use Case Suitable for Normal Selling? Notes
Compliance Approval / Type Approval For commercial sale/import of communication, multimedia or hybrid equipment. Yes, normally this is the proper route for selling. Use this if the scooter will be sold commercially and has wireless/communication functions.
Hybrid Certification Scheme For hybrid products where communication module is built into another product, for example vehicle, appliance, toy, medical device, smart meter, etc. Likely, if scooter is treated as hybrid product. For scooter, this may apply if the wireless module is embedded inside the vehicle/product.
Special Approval For special / limited purposes such as sample, trial, demo, personal, temporary import, exhibition or non-commercial use, subject to SIRIM approval category. Usually not enough for normal selling. SIRIM Special Approval document states Special Approval cannot be treated as Compliance Approval / Type Approval and equipment can only be used as specified in the Special Approval.
Practical interpretation for scooter: If the scooter has Bluetooth / app control / 4G GPS tracker and you want to sell it normally, submit enquiry to SIRIM eComM and ask whether it should be under Type Approval / Compliance Approval or Hybrid Certification Scheme. Do not rely on Special Approval for normal commercial sale unless SIRIM confirms it is acceptable.

5. Flow Details

1Confirm Wireless Function

Purpose: Determine whether the scooter has any wireless/communication module.

Ask supplier to confirm:

  • Does the scooter have Bluetooth?
  • Does it support mobile app connection?
  • Does it have WiFi?
  • Does it have GPS tracking?
  • If GPS exists, is it receiver-only or does it have SIM/4G/GSM communication?
  • Does it have NFC, RFID, Zigbee, LoRa, NB-IoT or other wireless module?
  • Does it have remote lock/unlock, anti-theft tracking, or cloud connection?

Status: Mandatory first step

2Collect Wireless Module Documents

Purpose: Prepare the technical file before enquiry/application.

Documents needed from supplier:

  • Wireless module brand and model
  • Wireless module datasheet
  • Frequency band
  • RF output power
  • Antenna specification
  • Antenna gain
  • RF test report
  • CE / FCC report, if available
  • Product photos
  • Internal photos showing module location, if available
  • User manual
  • Product label artwork
  • App description
  • Bluetooth / WiFi / GPS / 4G function description
  • Importer details
  • Supplier / manufacturer details
  • Brand authorization letter, if applicable

Status: Mandatory if wireless exists

3Submit Enquiry to SIRIM eComM

Purpose: Confirm the correct approval route before submitting the actual application.

Platform: SIRIM eComM Portal

Attach / include in enquiry:

  • Product name: Electric scooter / micromobility vehicle
  • Wireless function summary
  • Wireless module brand/model
  • Datasheet
  • Frequency band and RF output power
  • Product photos
  • User manual
  • Whether product is for commercial sale or sample/trial

Question to ask SIRIM:

Please advise whether this product should be applied under Compliance Approval / Type Approval, Hybrid Certification Scheme, or Special Approval. The product is an electric scooter with [Bluetooth/WiFi/GPS/GSM/etc.] and will be imported for [commercial sale/sample/testing].

Status: Strongly recommended before application

4Apply Type Approval / Hybrid Certification / Special Approval

Purpose: Submit the official application based on SIRIM’s advice.

Documents normally needed:

  • Company / importer details
  • SSM company registration
  • Authorised person details
  • Product catalogue / brochure
  • User manual
  • Product photos
  • Product label artwork
  • Wireless module datasheet
  • RF test report / CE / FCC report, if available
  • Antenna details
  • Frequency band and output power
  • Brand authorization letter, if applicable
  • Invoice / shipment details, if applying for Special Approval or clearance-related route
  • Application fee/payment

Status: Mandatory if wireless approval applies

5Evaluation / Testing

Purpose: SIRIM reviews the application and may accept existing reports or request local testing/additional documents.

Possible requests from SIRIM:

  • Additional RF test report
  • Sample unit for testing
  • Clarification on frequency band
  • Clarification on antenna gain or module location
  • Corrected product label/manual
  • Manufacturer authorization or declaration

Status: Depends on SIRIM review

6Approval Certificate

Purpose: Obtain approval before commercial sale/import of wireless communication equipment.

Outcome:

  • Compliance Approval / Type Approval certificate, if approved under normal commercial route
  • Hybrid certification approval, if classified under hybrid product route
  • Special Approval certificate, if approved for specified limited purpose

Status: Mandatory if product has regulated wireless function

7MCMC Label / Self-Labelling Program

Purpose: Ensure the approved communication equipment carries the required MCMC label / marking where applicable.

Documents / actions may include:

  • Approval certificate reference
  • Product label artwork
  • SLP / label registration details, if applicable
  • Label placement on product / packaging / manual, depending on approval condition

Status: Mandatory if required by approval condition

8. Message to Supplier

Hi, for Malaysia SIRIM/MCMC checking, please confirm whether this scooter has any wireless module such as Bluetooth, WiFi, GPS, GSM/4G, NFC, RFID, Zigbee, LoRa, NB-IoT or app control. If yes, please provide the wireless module brand/model, module datasheet, frequency band, RF output power, antenna specification/gain, RF test report, CE/FCC report if available, product photos, internal photos showing module location, user manual, product label artwork, and description of the Bluetooth/WiFi/GPS/app function.

10. Quick Copy Summary

SIRIM/MCMC Wireless Approval Flow: 1. Confirm whether scooter has Bluetooth, WiFi, GPS tracker, GSM/4G, NFC, RFID, Zigbee, LoRa, NB-IoT or app control. 2. If no wireless module, SIRIM/MCMC is usually not applicable. 3. If wireless module exists, request supplier documents: module datasheet, frequency band, RF output power, antenna details, RF report, CE/FCC report, product photos, internal photos, manual and label artwork. 4. Submit enquiry to SIRIM eComM to confirm correct route. 5. For commercial sale, likely route is Compliance Approval / Type Approval or Hybrid Certification Scheme. 6. Special Approval is normally for limited/specified use and should not be treated as full Type Approval for normal sale unless SIRIM confirms. 7. Submit application, respond to SIRIM queries/testing requests, obtain approval certificate, and complete MCMC labelling/SLP if required.

11. Key Reminder

CE/FCC/RF reports are useful supporting documents, but they do not automatically replace Malaysia SIRIM / MCMC approval. For normal commercial selling, confirm with SIRIM whether Type Approval / Compliance Approval or Hybrid Certification Scheme is required.
